# 🐱 Cat World Launcher

**Официальный лаунчер игры Cat World**

Cat World Launcher — это удобный лаунчер, который позволяет скачивать, устанавливать и обновлять игру Cat World прямо из приложения.

## ✨ Возможности

- 📥 Скачивание и установка игры.
- 🔄 Автоматическая проверка обновлений.
- 📦 Загрузка игровых файлов с GitHub Releases.
- 🛠️ Проверка целостности игровых файлов.
- 🎮 Запуск игры прямо из лаунчера.
- 💻 Поддержка Windows и macOS.
